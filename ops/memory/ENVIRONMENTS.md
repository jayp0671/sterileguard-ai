## Gotchas

- A key pasted into Vercel or Render that is changed by the copy gives 401 at Supabase's gateway (it shows in Supabase edge logs, not auth logs). Copy with:
  `((Get-Content .env | Where-Object { $_ -like 'NAME=*' }) -replace '^[^=]*=','') | Set-Clipboard`
